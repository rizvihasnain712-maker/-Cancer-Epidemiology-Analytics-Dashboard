# -Cancer-Epidemiology-Analytics-Dashboard
An interactive Power BI dashboard designed to analyze and visualize cancer epidemiology data. This project provides insights into patient demographics, cancer types, age groups, regional survival patterns, and treatment costs.
📊 Dashboard Highlights
👥 1,000 patient records analyzed
🧬 16 cancer types covered
🌍 Data across 7 regions
📈 Cancer distribution by age group
⚕️ Patient survival analysis by income and region
💰 Treatment cost comparison in millions
🗂️ Cancer type distribution using a Treemap
🎯 Interactive gender filters for data exploration

🎯 Project Objective

The main objective of this project is to transform healthcare data into clear and interactive visualizations that make it easier to identify patterns, compare cancer types, understand survival trends, and analyze treatment costs.
